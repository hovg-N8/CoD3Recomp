## The correction that matters most

The 2026-11-11 notes said struggles, driving and live-grenade throw-backs "cancel for a non-local player" because of
sub_82535A40 / sub_82535B78. THAT WAS WRONG:
- 0x820960A0 is the .pdata (exception) table, not a table of script built-ins.
- sub_82535A40 / sub_82535B78 are called by the client game's entity-event code sub_8244C248 for events 1..23 and
  70..92: groups of 23 = one per surface type (footsteps, landings). 0x8253xxxx is the sound code (coop_probe.cpp
  hooks 82535460..82535788 as sounds). Their "local player only" test is a rumble/sound of this machine's player.
- The real reader of the action definitions (PlayAnims ... VehicleLink, PickLiveGrenade; names at 0x825D1190,
  controls 0x825D1168, blends 0x825D11FC, buttons 0x825D1220) is sub_824F3308: action type at +32, control at +36.
  The module is 0x824F0000..0x8250FFFF. Whether an action can run for client 1 is UNKNOWN: to be read from a run.
