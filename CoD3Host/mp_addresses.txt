# Single player address -> multiplayer address, for the host code built into
# CoD3MP.exe (scripts/make_mp_host.py). The multiplayer executable,
# codmp_xenonf.xex, is the same engine linked at other addresses: every
# function and variable the host hooks or reads has a twin there.
#
# How these were found (tools/mpmap/): functions by their instructions with
# the addresses masked out, a whole function matched once, or a window of it
# between two functions that match whole; variables by reading what the
# multiplayer twin of each function that names one names at the same
# instruction (the votes are how many such places agreed).
#
# A line is "SP MP  # how". MP 00000000 means there is no such thing in
# multiplayer: a comparison against it never holds.
