# CoD3 Launcher V3 (0.3.3)

Extract the player ZIP and run CoD3Launcher.exe. Keep its config file and
public-key.xml beside it. Your saved installation folder carries over.

- Check for Updates runs the signed release check and applies available updates.
- Installed build comes from VERSION.txt. The launcher displays 0.6.4 as
  0.6.04. Published build comes from the
  verified online release. If your local development build is newer, it is kept.
- Patch Log searches the complete project notes through 0.6.04, starting at
  the 0.4.0 original port. It also reads newer installed PATCH-NOTES.txt
  entries and the published release summary. The embedded archive works offline.
- Next Scene previews each artwork. Rotate artwork advances every 12 seconds
  while the launcher is visible and the game is closed.
- Ten scenes rotate, including Village Under Fire and Typhoons Over Normandy.
- Frontline Mix plays the complete supplied Sgt. MacKenzie recording, with
  excerpts from the supplied Eastern Front audio and quiet original ambience.
  The battlefield and ambience layers have 5% more gain than in V3.2.
  Battle Ambience and Sound Off are available in the soundtrack selector.
  Audio stops while a game started from the launcher is running.

Credits go to Treyarch for the original game, FrankHUN88453 for the
original CoD3Recomp PC port, and JARC for the community enhancements.

The player ZIP updates the launcher. The launcher continues to use the
existing Cloudflare service and release signing key. For later game releases,
include the full PATCH-NOTES.txt in your release installation so players can
browse the new entries when the game update arrives.
