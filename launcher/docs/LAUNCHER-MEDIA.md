# Launcher battlefield presentation

Player launcher update: original WWII background art, procedural quiet battle
ambience, optional audio checkbox, persisted preference, pause during gameplay,
and clean shutdown. Media is embedded in the player EXE; no cloud feed or game
file changes are required. Player packages keep their matching public key.

Audio is original synthesized ambience (wind, distant rifle/machine-gun bursts,
low artillery and debris), with conservative peak level. It changes no Windows
volume setting and contains no extracted game soundtrack.
